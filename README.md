# 🌐 My Portfolio

A modern and responsive **Personal Portfolio Website** built using **HTML5, CSS3, and JavaScript**.

This project showcases my skills, projects, education, and contact information in a clean and professional way. It serves as my personal portfolio to demonstrate my web development journey and projects.

---

## 🚀 Features

- Responsive Design
- Modern UI
- Home Section
- About Me
- Skills Section
- Projects Showcase
- Contact Section
- Smooth Scrolling
- Interactive JavaScript Features
- Mobile Friendly

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
